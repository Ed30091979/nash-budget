# Исследование: как выглядят денежные приложения 2025–2026

Собрано для переработки дизайна «Наш бюджет». Каждое число здесь взято из первоисточника —
спецификации, исходников дизайн-системы или статьи Nielsen Norman Group. Помечено:
**[спек]** — из первоисточника, **[вторично]** — из разбора.

Документ описательный. Нормативен `DESIGN.md`: то, что мы принимаем отсюда, переезжает туда.

---

## 1. Иерархия экрана

**Одно доминирующее число.** У Mercury общий баланс — самый крупный текст на странице, он отвечает
на вопрос «я в порядке?». Важное число безошибочно самое крупное, вторичное сгруппировано и
приглушено. **[вторично]**
→ Принимаем: на главном ровно один герой-номер, а не три равновеликие плитки.

**Приоритетная одна колонка вместо сетки плиток.** Тренд 2026 — вертикальный список с одним
доминирующим следующим действием; мотивируется движением большого пальца и чтением в состоянии
денежного стресса. **[вторично]**
→ Принимаем: наша аудитория не финансисты, дашборд из виджетов ей вреден.

**Уплотнение, а не прятание.** Monarch в редизайне сократил высоту строки транзакции, сделал
группы счетов и разделы бюджета сворачиваемыми. **[вторично]**
→ Принимаем: сворачиваемые секции лучше вкладок.

**Бюджет высоты.** iPhone 390×844 pt, safe-area сверху ~59, снизу 34; плавающий таб-бар iOS 26
отступает по 21 pt. Арифметика: 844 − 59 − 34 = 751, минус нижняя навигация 70–90 →
**на первый экран без прокрутки приходится 560–620 pt.** **[спек + расчёт]**
→ В них помещается герой-число, один индикатор и начало списка. Больше не помещается.

## 2. Суммы

**Табличные цифры обязательны, и системный шрифт их сам не включает.** San Francisco по умолчанию
рендерит **пропорциональные** цифры, в отличие от большинства гротесков. Нужно явно
`font-variant-numeric: lining-nums tabular-nums`; поддержано всеми браузерами с января 2020. **[спек]**
→ Принимаем как обязательное. Без этого суммы в списке «пляшут».

**Знак валюты светлее суммы.** Эталон Stripe: табличные цифры, выравнивание вправо, единое число
знаков после запятой, символ валюты набран светлее значений. **[вторично]**

**Части числа набираются раздельно через `Intl.NumberFormat().formatToParts()`.** Для `ru-RU`/`RUB`
разделитель разрядов и отбивка перед ₽ — неразрывный пробел U+00A0, десятичный — запятая. Метод
отдаёт типизированные куски `minusSign / integer / group / decimal / fraction / currency`. **[спек]**
→ Принимаем: крупные рубли, мелкие копейки, светлый ₽ — без ручного разбора строк.
→ И отдельно: **минус набирать U+2212, а не дефис** — в табличном режиме он равен ширине цифры.

**Русская типографика.** Знак валюты справа с отбивкой (Ководство §74: «не писать пробел перед
знаком — всё равно что писать 50руб»); десятичный разделитель — запятая; разряды отбиваются
неразрывным пробелом, в таблицах — даже у четырёхзначных; суммы выравниваются по правому краю, при
дробной части — по запятой; номера счетов и ID остаются слева. **[руководства уровня спеки]**

**В одновалютном списке ₽ можно убрать совсем** и дать целой части больший вес, чем дробной. **[вторично]**
→ Принимаем: ₽ только на герой-числе, в строках он шум.

**Шкала iOS (Large).** Large Title 34/41, Title 1 28/34, Title 2 22/28, Title 3 20/25, Headline 17
Semibold/22, Body 17/22, Callout 16/21, Subhead 15/20, Footnote 13/18, Caption 1 12/16, Caption 2
11/13. Минимум — 11 pt. На AX1 Body становится 23 pt, на AX5 — 47 pt. **[спек, HIG]**
→ Герой 34–40 px, подпись 15, метки 13. Проверять вёрстку при масштабе ×2.7.

**Эмфаза весом, а не размером.** В «emphasized»-вариантах Material 3 кегль не меняется, растёт
только вес: Display Large 57sp Regular → Medium, Label Large 14sp Medium → Bold. **[спек, исходники androidx]**
→ Ценно при дефиците высоты: «превышен лимит» выделяем весом на том же кегле.

## 3. Глубина

**Тени — накопительный стек полупрозрачных слоёв** (дизайн-система Альфа-Банка, исходники): **[спек]**
```
--shadow-xs: 0 4px 8px rgba(0,0,0,.04), 0 0 1px rgba(0,0,0,.04);
--shadow-s:  0 12px 16px rgba(0,0,0,.04), 0 4px 8px rgba(0,0,0,.04), 0 0 1px rgba(0,0,0,.04);
--shadow-m:  0 20px 24px rgba(0,0,0,.08) + предыдущие слои
```
Каждый уровень **добавляет** слой, а не заменяет — тень остаётся мягкой и не грязнит светлый фон.
→ Нам хватит xs и s.

**Возвышение Material 3:** 0 / 1 / 3 / 6 / 8 / 12 dp. Карточка — уровень 1, лист — 3, не больше. **[спек]**

**Скругления.** M3: 4/8/12/16/20/28/32/48. Альфа: шаг 2 px плюс `--border-radius-pill: 99px`. **[спек]**
→ Явный pill-токен убирает магические числа на чипах категорий.

**Концентричные углы iOS 26: радиус внутреннего = радиус внешнего − отступ.** **[вторично, описание `ConcentricRectangle`]**
→ Вложенная карточка в карточке 16 px с падингом 8 получает радиус 8. «Дорогое» ощущение бесплатно.

**Scroll edge effect.** iOS переключает мягкий/жёсткий вариант по позиции прокрутки. **[спек Apple]**
→ Упрощаем: шапка прозрачна в нуле и получает фон с границей после `scrollTop > 0`.

## 4. Графики и прогресс

**Для количества — только длина и 2D-позиция.** Площадь и угол передают количество плохо, поэтому
пироги и донаты «непригодны для большинства задач передачи информации». Цвет кодирует категорию, а
не величину. Столбцы упорядочивать. Дальтонизм: ~8 % мужчин. **[NN/g]**
→ Расход по категориям — горизонтальные бары по убыванию, не донат.

**Полоса «потрачено из лимита» с маркером темпа месяца — один градиент на фоне строки.** Из
исходников Toolkit for YNAB: **[спек]**
```
linear-gradient(to right, var(--pacing-fill) X%, var(--row-bg) X%)
```
Поверх — вертикальный маркер «сколько месяца прошло» шириной 0,1 %. Порядок стопов меняется в
зависимости от того, обгоняешь ты календарь или отстаёшь.
→ Принимаем: ноль лишних узлов DOM, работает на любой строке. Маркер «сегодня» объясняет семье
«вы идёте с опережением», ничего не запрещая.

**Дневной «можно потратить».** Свободный остаток после обязательных платежей делится на дни до
следующего дохода и пересчитывается после каждой траты. **[вторично]**
→ Для нашей аудитории одно число понятнее таблицы категорий.

**График всегда с текстовым выводом.** Apple: добавлять заголовок, который сам сообщает вывод; если
задача просто показать значения — лучше список. **[спек Apple]**
→ «В августе потратили на 12 % меньше, чем в июле» — над графиком, а не под ним.

## 5. Пластика

**Длительности Material 3** **[спек, исходники]**: short 50/100/150/200, medium 250/300/350/400,
long 450–600, extra-long 700–1000 ms.
→ Нажатие 100, смена вкладки 200–250, появление листа 300–400.

**Кривые M3** **[спек]**: emphasized `cubic-bezier(0.2,0,0,1)`, accelerate `(0.3,0,0.8,0.15)`,
decelerate `(0.05,0.7,0.1,1)`, standard `(0.2,0,0,1)`.
→ Появление — decelerate, уход — accelerate.

**Пружины.** standard spatial: damping 0.9 / stiffness 700. expressive: 0.8 / 380 — с видимым
отскоком. effects (цвет, прозрачность) в обеих схемах: damping **1.0**, то есть без отскока. **[спек]**
→ Берём standard: наш тон спокойный, не трейдинговый. Цвет и прозрачность не пружинят никогда.

**Одометр на числе.** Каждая цифра — катушка в слоте шириной `1ch` с `overflow: hidden`; табличные
цифры обязательны; `aria-live="polite"` объявляет итог, а не промежуточные цифры; при
`prefers-reduced-motion` — мгновенный снап. **[вторично, с точными требованиями]**
→ Принимаем, но длительность 200–300 ms, а не 2,8 s как в витрине.

**Движение объясняет, а не развлекает.** Число анимируется, чтобы стало понятно, что оно
изменилось. **[вторично]**

## 6. Пустые состояния и загрузка

**Три правила NN/g:** сообщить состояние системы («Нет записей за выбранный период», и не врать
«нет данных», если через секунду они появятся); дать обучающую подсказку — что сюда попадает;
дать прямой путь к задаче — кнопку действия. Loggly предлагает два выхода: подключить источник
**или посмотреть демо-данные**. **[NN/g]**

**Пороги индикаторов:** < 1 s — индикатор не нужен вообще; 2–10 s — скелетон или спиннер; > 10 s —
полоса с оценкой. Пульсирующие скелетоны «могут отвлекать, раздражать или создавать проблемы
доступности». **[NN/g]**
→ Для офлайн-первого PWA рендер почти всегда < 1 s: индикаторов быть не должно, кроме первой
синхронизации.

**Порядок онбординга Copilot:** сначала ручное добавление счёта, только потом запрос банковских
данных — это заметно повышает доверие. **[вторично]**
→ Демо-режим с примером семейного бюджета — лучший первый экран для аудитории, которая боится
привязывать банк.

## 7. Строка операции

**Анатомия Material 3** **[спек, исходники]**: одна строка 56 dp, две — **72**, три — 88. Ведущая
иконка 24 dp, ведущий аватар **40 dp, круг**. Заголовок Body Large 16sp, подпись Body Medium 14sp,
трейлинг-подпись Label Small 11sp Medium.
→ Наша строка: 72 dp, слева плитка 40, справа сумма 16 табличными, время 11.

**Строка адаптируется под тип операции.** Monzo раскрывает разное для валютной операции и платежа;
Starling показывает все одинаково — и это названо проигрышем. **[вторично]**
→ У нас нет мерчантов, но есть перевод между счетами, регулярный платёж, трата ребёнка — им нужны
разные вторые строки.

**Виртуализация длинных списков обязательна.** **[вторично]**

**Атрибуция «чьё».** Monarch в 2026 добавил разметку «yours, mine, and ours» — личные траты отдельно
от общих. **[вторично]**
→ Для российской семьи это ключевая ось. Визуально — аватар-инициал 20–24 px, не второй крупный
элемент.

## 8. Иконки категорий

**SF Symbols нам недоступны юридически:** лицензия ограничена платформами Apple и не покрывает веб
и кросс-платформенные приложения. **[спек лицензии]**
→ Только открытые наборы, инлайном: Lucide (ISC), Phosphor, Remix Icon.

**Сетка «глиф в плитке»:** плитка 40×40, скругление 10–12, глиф 20–24 по центру, тонированный фон
категории и насыщенный глиф. **[спек M3 + вывод]**

**Цвет — только метка категории, никогда величина.** **[NN/g]**

## 9. Российский контекст

**Альфа-Банк отгружает в проде системный шрифтовой стек** для всего текста: **[спек, исходники core-components]**
```
--font-family: system-ui, -apple-system, 'Segoe UI', Roboto, 'Helvetica Neue', Helvetica, sans-serif;
```
Брендовый Styrene применяется только к заголовочным миксинам. Высоты контролов: 32/40/**48**/56/64/72.
→ Прямое подтверждение нашего ограничения: крупный банк живёт на системном шрифте. Их размер «s» =
48 px совпадает с нашей целью ≥48 pt.

**Sber Plasma масштабирует интерфейс через `font-size` на `<html>`** — все размеры в `rem`, на разных
поверхностях корень 16 или 32 px. **[спек]**
→ Механика «крупный шрифт» для родителей 45+: один переключатель, вёрстка едет следом.

**CoinKeeper против Дзен-мани:** первый держит категории с бюджетами прямо на главном и ввод одним
жестом, второй — автоимпорт и подробную аналитику. **[вторично]**
→ Без автоимпорта нам ближе модель CoinKeeper, но метафора перетаскивания монеты конфликтует с
целями ≥48 pt.

## 10. Доступность: чем мерить

**Цели нажатия.** Material: минимум 48×48 dp ≈ 9 мм, зазор между целями ≥8 dp. WCAG 2.2 SC 2.5.8
(AA): 24×24 CSS px с исключением по расстоянию; SC 2.5.5 (AAA): 44×44. Apple: 44×44 pt. **[спек]**
→ **Наш порог 48 pt строже всех трёх.** Оставляем.

**Контраст.** AA: 4.5:1 для текста, 3:1 для крупного текста и **нетекстовых элементов** — границ
контролов, иконок-состояний. Прямое предупреждение по нашей палитре: светлые и мятные зелёные
**проваливают контраст как текст на белом**, они годны только для фонов и подсветок. **[спек + вторично]**
→ Мятный — только заливка. Текст и глифы — тёмно-зелёные. Границы контролов проверять на 3:1.

## Противоречит нашим ограничениям — не берём

**Liquid Glass целиком.** Настоящее преломление, адаптивная инверсия по подложке и «стекло на
стекле» в вебе не воспроизводятся; полупрозрачность на светлом мятном фоне съедает контраст;
`prefers-reduced-transparency` поддержан не везде. → Ничего смыслонесущего на стекле не строим.

**Прогрессивное размытие в семь слоёв.** Chromium ломается на стопке `backdrop-filter` с масками и
`overflow: hidden`, обходной путь «ресурсоёмок и иногда лагает», нативный синтаксис ещё только
предложен в CSSWG. → Заменяем одним линейным градиентом-скримом 64–96 px под нижней панелью.

**Брендовые шрифты.** Styrene, SB Sans, TypeType, Inter и любая типографика с CDN запрещены нашей
политикой безопасности. → Системный стек. Побочный эффект: у нас нет альтернативных наборов цифр,
поэтому вся работа с числами идёт через `font-variant-numeric` и вёрстку.

**`ui-rounded`.** Только Safari (~16 % глобально). → Допустимо как прогрессивное улучшение герой-числа,
но макет проектируется под обычный `system-ui`.

**Эмодзи как иконки категорий.** Рендерятся шрифтом операционной системы, то есть по сути внешним
ресурсом; плохо читаются вслух; ломают спокойный тон. У нас запрещены — и правильно.

**Пружины expressive.** Отскок 0.6–0.8 не наш тон.

**Донаты и пироги.** См. NN/g выше.

**Красный как основной сигнал перерасхода.** Часть платёжных приложений заменяет его оранжевым,
чтобы не провоцировать панику; «стыдящие» подталкивания критикуются. → Янтарный для «идёте с
опережением темпа», красный только для факта превышения лимита, и состояние всегда дублируется не
цветом — иконкой, подписью, позицией маркера.

## Чего подтвердить не удалось

Постраничных разборов экранов Т-Банка, Сбербанк Онлайн и ВТБ за 2025–2026 с конкретными числами в
открытом доступе нет: российские банки публикуют дизайн-системы (Taiga UI, Plasma, core-components),
но не разборы экранов. Числа Material 3 взяты напрямую из исходников `androidx`, а не из
документации, которая рендерится на JavaScript. Конкретика по маркеру темпа — из исходников
Toolkit for YNAB, поскольку официальная статья YNAB отдаёт 404.
