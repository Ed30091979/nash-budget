# Публикация «Наш бюджет» 1.0.0 в RuStore — пошагово

Артефакты готовы локально; загрузку в консоль выполняет владелец аккаунта.

## Что уже готово

- Подписанный AAB: `outputs/release-1.0.0/nash-budget-1.0.0.aab` (подпись `upload`, jarsigner: jar verified).
- Ключ подписи: `~/.nashbudget-release/upload-keystore.jks`, пароль в `~/.nashbudget-release/keystore-password.txt` (alias `upload`, RSA-4096, действителен до 2053 года).
- Иконка 512×512 и 5 скриншотов 1080×1920: `outputs/release-1.0.0/store-assets/`.
- Тексты карточки: `docs/store/rustore-card.md`.
- Политика конфиденциальности: `docs/store/privacy-policy.md` — **нужно опубликовать на публичном URL** (подойдёт GitHub Pages, Notion-страница или любой сайт).

## Перед загрузкой (критично)

1. **Сохраните ключ**: скопируйте оба файла из `~/.nashbudget-release/` минимум в два надёжных места (менеджер паролей + офлайн-носитель). Потеря ключа = невозможность обновлять приложение той же записью.
2. Перенесите пароль из `keystore-password.txt` в менеджер паролей и удалите текстовый файл.
3. Проверьте установку на реальном устройстве: `apps/android/.../app-debug.apk` — первый запуск в авиарежиме, создание бюджета, перезапуск.

## Шаги в RuStore Console (console.rustore.ru)

1. Войдите через свой VK ID → «Приложения» → «Добавить приложение».
2. Тип: «Приложение», распространение: бесплатно.
3. Package name: `ru.nashbudget.app` (изменить после публикации нельзя).
4. Загрузите `nash-budget-1.0.0.aab` во вкладке «Версии».
5. Заполните карточку по `rustore-card.md`: название, короткое и полное описание, категория «Финансы», возраст 0+.
6. Загрузите иконку и скриншоты из `store-assets/`.
7. В декларации данных укажите: данные не собираются и не передаются; разрешений нет.
8. Укажите URL политики конфиденциальности и почту поддержки.
9. Тестирование: создайте **закрытое альфа-тестирование**, добавьте свои устройства, проверьте установку из RuStore, работу офлайн и сохранение данных при обновлении.
10. После альфы отправьте версию на модерацию; включите поэтапный rollout (5% → 20% → 50% → 100%).

## После публикации

- Подпишитесь на статусы модерации в консоли; ответы на отзывы — из консоли.
- Следующие версии: поднимайте `versionCode` (+1) и `versionName`, собирайте `pnpm --filter @family-budget/android verify:android`, подписывайте тем же ключом:
  `jarsigner -keystore ~/.nashbudget-release/upload-keystore.jks -sigalg SHA256withRSA -digestalg SHA-256 <aab> upload`
- Перед следующим релизом перепроверьте статус Android Developer Verification (RuStore применяет проверку с 30.09.2026).
