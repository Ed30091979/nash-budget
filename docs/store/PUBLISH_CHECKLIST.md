# Публикация «Наш бюджет» в RuStore

## Статус

Версия **1.0.0 (versionCode 1)** отправлена на модерацию 1 августа 2026 года. Публикация — автоматическая сразу после одобрения, аудитория 100%. Приложение в консоли: `console.rustore.ru/apps/2063740400`.

## Итоговая identity

- Package name: **`com.edfurman.nashbudget`** — изменить после публикации невозможно.
- Исходно планировался `ru.nashbudget.app`, но RuStore отклонил его: «Пакет с таким именем уже существует» (имя занято чужой записью в магазине, в публичном каталоге не опубликовано). Имя перенесено в namespace владельца аккаунта, как у `com.edfurman.upword`.
- Ключ подписи: `~/.nashbudget-release/upload-keystore.jks`, alias `upload`, RSA-4096, действителен до 2053 года; пароль в `keystore-password.txt` рядом. Сертификат SHA-256 `1361eea1a517d145b9687dfecc66806ff68010f2449078112d5402a19d33ee79`.
- Формат публикации — **APK**. Для AAB RuStore требует загруженную подпись предыдущей версии, которой у нового приложения нет; для APK загрузка подписи не нужна.

## Что осталось за пользователем

1. **Сохраните ключ**: скопируйте оба файла из `~/.nashbudget-release/` минимум в два надёжных места (менеджер паролей + офлайн-носитель). Потеря ключа = невозможность обновлять приложение этой записью.
2. Перенесите пароль из `keystore-password.txt` в менеджер паролей и удалите текстовый файл.
3. Перевыпустите ключ RuStore API (раздел «Разработчик» → «RuStore API»), если приватный ключ передавался небезопасным каналом.
4. Проверьте установку на реальном устройстве после публикации: первый запуск в авиарежиме, создание бюджета, перезапуск.

## Следующие версии

- Поднимайте `versionCode` (+1) и `versionName`, собирайте `pnpm --filter @family-budget/android verify:android`.
- Подписывайте тем же ключом:
  `apksigner sign --ks ~/.nashbudget-release/upload-keystore.jks --ks-key-alias upload --out <out.apk> <aligned.apk>`
- Начиная со второй версии доступен Public API: `node tools/publish-rustore.mjs` и `--submit` (ключ в `~/.nashbudget-release/rustore-api.env`).
- Поэтапный rollout (5% → 20% → 50% → 100%) доступен со второй версии; первая публикуется только на 100%.
- Перед следующим релизом перепроверьте статус Android Developer Verification (RuStore применяет проверку с 30.09.2026).
