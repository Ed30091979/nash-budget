# Карточка RuStore — «Наш бюджет»

Все материалы соответствуют фактическому поведению приложения. Скриншоты и иконка лежат в `outputs/release-1.0.0/store-assets/`.

> **Внимание: карточка изменилась не косметически.** Версия 1.0.0 заявляла в декларации данных «сбор и передача отсутствуют». С появлением необязательной семейной синхронизации это утверждение перестаёт быть полным: при включении синхронизации приложение собирает адрес электронной почты. Раздел «Декларация данных» ниже переписан целиком и требует **повторной подачи в консоли RuStore**.

## Что должен сделать пользователь руками

Этим планом ничего из перечисленного не выполняется и выполнено быть не может — всё требует входа в консоль RuStore и на хостинг:

1. **Опубликовать обновлённую политику конфиденциальности** по публичному URL и указать этот URL в карточке. Текст — `privacy-policy.md`, в нём остались заполнители, которые надо заполнить до публикации.
2. **Заново подать декларацию данных** в консоли RuStore по разделу «Декларация данных» ниже. Прежняя декларация («типы данных не выбраны») станет недостоверной в момент выпуска сборки с настроенным адресом сервера синхронизации.
3. **Принять решение по возрастной маркировке** — см. раздел «Возрастная маркировка: открытый вопрос».
4. **Подать уведомление об обработке персональных данных в Роскомнадзор** — до первого реального пользователя сервера, а не после запуска (ст. 22 152-ФЗ).
5. Обновить короткое и полное описание в карточке по текстам ниже.

## Короткое описание (до 80 символов)

> Семейный бюджет: план на год, лимиты месяца, резерв к платежам. Офлайн.

## Полное описание

> «Наш бюджет» — спокойный планировщик семейных денег. По умолчанию он работает полностью на вашем устройстве: без регистрации, без интернета, без рекламы и аналитики.
>
> ЧТО УМЕЕТ:
> — План на 12–24 месяца: доходы, ежемесячные, сезонные и крупные ежегодные платежи;
> — Резерв к срокам: приложение подсказывает, сколько откладывать каждый месяц, чтобы страховка или обучение не стали сюрпризом;
> — Лимиты повседневных расходов и сигналы «почти лимит» / «перелимит»;
> — Быстрая запись операций: доходы, расходы, возвраты, переводы, накопления;
> — Дашборд план/факт, ближайшие платежи, поиск по истории;
> — Резервная копия в JSON и экспорт таблицы в CSV — вы сами выбираете, куда сохранить файл.
>
> СЕМЕЙНАЯ СИНХРОНИЗАЦИЯ — ПО ЖЕЛАНИЮ:
> Если бюджет ведут двое, можно связать устройства семьи. Для этого нужен только адрес электронной почты: на него приходит одноразовый код для входа. Записи бюджета шифруются на вашем устройстве, и сервер не может прочитать суммы, категории, названия счетов, имена участников и комментарии — ключ шифрования хранится только на устройствах семьи.
>
> Включать синхронизацию не обязательно. Без входа приложение работает как раньше: локально, офлайн, без учётной записи и без единого обращения к сети.
>
> ПРИВАТНОСТЬ ЧЕСТНО:
> Приложение не запрашивает системных разрешений, не содержит рекламы, трекеров и аналитики. Если вы включили синхронизацию, серверу видны служебные сведения: адрес почты, число участников семьи, размер каждой записи, а также кто из участников и в какое время её сделал — а при записи «по горячим следам» время записи почти совпадает с днём самой покупки. Содержимое бюджета ему недоступно. Полный перечень — в политике конфиденциальности.

## Что нового

> Появилась необязательная семейная синхронизация: бюджет можно вести вдвоём с нескольких устройств. Записи шифруются на устройстве, сервер не может прочитать суммы и категории. Без входа приложение по-прежнему работает полностью локально и офлайн.

### Формулировка для поля «сбор и передача данных»

> Приложение собирает адрес электронной почты — только если пользователь по своему решению включил семейную синхронизацию. Без этого сбор и передача данных отсутствуют полностью. Содержимое бюджета передаётся между устройствами семьи в зашифрованном виде и недоступно оператору; служебные сведения о записях — их автор, время доставки и размер — оператору видны и перечислены в политике конфиденциальности. Данные не передаются третьим лицам для их собственных целей, не используются для рекламы, аналитики и профилирования. Удаление аккаунта доступно в приложении.

### Комментарий модератору

> Приложение по умолчанию работает офлайн, без регистрации, данные хранятся только на устройстве. Дополнительно доступна необязательная семейная синхронизация: вход по адресу почты с одноразовым кодом, содержимое бюджета шифруется на устройстве сквозным шифрованием и серверу недоступно. Удаление аккаунта и всех данных семьи доступно из приложения. Системных разрешений нет.

## Возрастная маркировка: открытый вопрос

Версия 1.0.0 опубликована с маркировкой **0+**, и это было корректно для приложения, не собирающего данных. Со сбором адреса почты маркировка 0+ становится проблемной: для пользователей младше 14 лет обработка персональных данных требует согласия законного представителя, а такого механизма в приложении нет и не планируется.

Варианты, между которыми надо выбрать: сохранить 0+, зафиксировав в описании и политике, что аккаунт создаёт взрослый, либо поднять маркировку. Решение остаётся за пользователем — `[УКАЗАТЬ: выбранная маркировка и обоснование]`.

## Если сборка выпускается без синхронизации

Адрес сервера синхронизации задаётся конфигурацией сборки и в код не зашит. Сборка без этого адреса синхронизации не имеет физически: экран «Семья» сообщает, что синхронизация выключена, сетевой слой не загружается. Для такой сборки остаётся верной **прежняя** декларация «сбор и передача отсутствуют», и переподавать её не нужно.

Переподача декларации и публикация новой политики требуются начиная с той версии, в которой адрес сервера настроен и синхронизация доступна пользователю.
